# FPS-LAN — Roadmap

## Phase 0 — Foundation
- Unity project setup
- inspect packages
- choose networking solution
- establish project structure

## Phase 1 — Playable LAN MVP
- Host/Join
- LAN connection
- player movement
- FPS camera
- small map
- one rifle
- shooting
- damage
- death
- respawn
- Deathmatch
- scoreboard

## Phase 2 — Game Feel
- better weapon feedback
- sounds
- hit markers
- muzzle flash
- impact VFX
- recoil tuning
- movement tuning
- spawn tuning

## Phase 3 — Map Development
- improve layout
- improve cover
- improve sightlines
- alternate routes
- vertical gameplay
- visual identity
- spawn balancing

## Phase 4 — Weapons
- pistol
- SMG
- shotgun
- sniper
- additional weapon behaviors

## Phase 5 — Advanced Movement
Only add mechanics that improve actual gameplay:
- crouch
- slide
- double jump
- wall jump
- wall run
- dash
- air movement improvements

## Phase 6 — Abilities
Potential systems:
- mobility abilities
- defensive abilities
- offensive abilities
- cooldown-based mechanics

## Phase 7 — More Game Modes
Potential:
- Team Deathmatch
- Gun Game
- King of the Hill
- Capture Point
- other small-party modes

## Phase 8 — More Maps
Create multiple compact maps with different combat identities.

## Phase 9 — Polish
- menus
- settings
- graphics options
- audio mixing
- visual effects
- performance optimization
- better UI
- onboarding

## Important

The roadmap is not a commitment to implement everything.

Actual player feedback from LAN sessions should determine what gets developed next.

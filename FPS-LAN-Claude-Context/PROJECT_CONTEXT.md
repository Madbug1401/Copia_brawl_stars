# FPS-LAN — Project Context

## Overview

FPS-LAN is a small multiplayer FPS being developed in Unity for local LAN play with colleagues in the same physical workspace.

The project is intentionally experimental and iterative. The goal is to create a small FPS that becomes fun very quickly, then evolve it based on actual play sessions.

The game should feel arcade-like rather than realistic:
- fast movement
- frequent encounters
- short downtime
- responsive shooting
- readable maps
- satisfying combat feedback

The initial target is 2–4 players on the same LAN.

## Core Loop

Spawn → move → find opponents → fight → kill/die → respawn → fight again.

The player should spend most of a match engaged with the map and other players rather than searching for opponents.

## Long-Term Vision

Start with a tiny, stable LAN FPS and gradually add:
- better weapons
- more maps
- advanced movement
- abilities
- game modes
- progression/customization
- visual/audio polish

The game should grow through real playtesting instead of speculative feature development.
